# PhD Europe

Funded PhD positions (R1) in NL, DE, SE, DK, NO, FI — aggregated from EURAXESS,
viewable in a single editorial-style page with in-site detail view.

## Structure

```
phd-europe-app/
├── index.html              # SPA frontend, reads data/jobs.json
├── data/jobs.json          # generated by scraper (committed)
├── scraper/
│   ├── fetch.py            # EURAXESS HTML scraper
│   └── requirements.txt
└── .github/workflows/
    └── scrape.yml          # cron every 6h, commits jobs.json
```

## Local use

```bash
pip install -r scraper/requirements.txt
python scraper/fetch.py                 # list pages only (fast)
python scraper/fetch.py --with-details  # + per-job detail fetch (slow)
```

Then serve locally (fetch() is blocked on file://):

```bash
python -m http.server 8000
# open http://localhost:8000/
```

## Deploy (GitHub Pages + Actions)

1. Push this directory to a GitHub repo.
2. Settings -> Pages -> Source: Deploy from a branch -> main -> / (root).
3. Settings -> Actions -> General -> Workflow permissions: Read and write.
4. Actions tab -> enable workflows -> run "Scrape EURAXESS" once to seed data.

The cron then refreshes `data/jobs.json` every 6 hours.

```json
{
  "updated_at": "2026-04-19T14:00:00Z",
  "total": 523,
  "jobs": [
    {
      "id": "429722",
      "title": "PhD in Validation Frameworks",

      "country": "NL",
      "city": "Wageningen",
      "posted": "2026-04-15",
      "deadline": "2026-05-15",
      "profile": "R1",
      "research_fields": ["Computer Science"],
      "description": "...",
      "apply_url": "https://academictransfer.com/...",
      "euraxess_url": "https://euraxess.ec.europa.eu/jobs/429722"
    }

```

## Notes

- Source: EURAXESS — EU-mandated platform covering ~85%+ of public institutions.
- Filtered to `research_profile=1` (R1 early-stage PhD candidates).
- Polite 1s delay between requests; no auth needed.
- Apply links lead to the hiring institution (AcademicTransfer / Jobbnorge / etc.).
